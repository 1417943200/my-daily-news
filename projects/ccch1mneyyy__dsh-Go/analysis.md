## 它是什么
DSH Go 是 DeepSeek Harness 的第三方移动客户端，非官方项目。它在手机端提供完整聊天界面、内置 Linux 运行环境，并能远程连接电脑或服务器上的 DSH。Android 版已发布，iOS 仍处测试，鸿蒙代码已合入主线但暂不提供安装包。

## 为什么火
在很短时间内拿到 2.7 万 Star，曾上 Trendshift 全语言日榜第一。核心是切中了一个真实痛点：原本 DeepSeek Harness 主要在电脑或服务器上用，想在手机上跑要么 Root，要么自己折腾 Termux；DSH Go 把整套环境装进了 App，还能远程接管电脑上的 DSH，配合插件和手机操控，玩法明显比普通聊天客户端重。

## 技术栈
- UI 层：Dart / Flutter，支持 Android 8+，iOS 和鸿蒙共线开发。
- 原生层：Android Kotlin，iOS Swift / WidgetKit（开发中）。
- 客户端包：packages/dsh_client（DSH Web API）、packages/dsh_remote（DSH Remote 客户端）。
- 运行时：runtime/ 提供 Android Linux 运行时、iOS 特化、引擎补丁和 App 桥接。
- 许可证：主仓库 AGPL-3.0，sdk/ 与 examples/ 为 MIT。

## 核心能力
- **本机运行**：App 内安装 Ubuntu、Node.js 与 DSH 运行环境，免 Root、免 Termux。
- **远程连接**：通过 SSH 或 DSHarness Remote 连接电脑、服务器上的 DSH。
- **聊天与工具**：切换模型、发图、语音输入、处理工具审批和提问，支持原生界面与网页模式。
- **插件界面**：提供 SDK、教程和示例，可适配原生工具卡、表单和面板。
- **手机操控**：在授权后让本机引擎读屏、点击、输入，支持三档确认和免确认模式。
- **分享与外观**：分享卡、端到端加密对话回放、六个主题色、桌面图标、桌宠 Deepy 和鲸娘。
- **酒馆与宠物**：v1.2.0 加入酒馆助手接口、AI 宠物包制作、会话搜索等增强。

## 适用场景
适合想在移动端继续使用 DeepSeek Harness 工具链、自动化任务或远程控制电脑上 DSH 的开发者/极客。也适合喜欢插件扩展、手机操控和桌宠这类重交互体验的用户。需要注意：模型请求仍然发给外部提供方并计费，本机运行不等于离线；手机操控涉及无障碍权限，默认有敏感操作保护，建议保留。

## 同类对比
相较官方 DeepSeek App/网页，DSH Go 重点不是单纯聊天，而是把 Harness 的工具执行、插件和跨设备控制搬上手机。相较在 Termux 里手动安装 DSH，它内置运行环境，安装和配置门槛更低。远程场景则能接入 DSHarness Remote，让手机成为电脑侧 DSH 的控制端。不过远程连接目前只支持图片附件，不能在 App 内打开网页版，插件管理限于开关，且不支持 DS Bot 和对话日志导出。
