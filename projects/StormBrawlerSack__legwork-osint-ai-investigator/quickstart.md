## 安装
- 访问 https://awesomeosint.tools/legwork/ 下载 Windows 版安装包。
- 按安装向导完成安装（README 未提供命令行或源码构建方式）。

## 最小可用示例
1. 启动 Legwork。
2. 在输入框输入问题，例如：Who is behind johndoe.example?
3. 等待答案逐行生成，观察粉色高亮短语和每句旁的来源编号。
4. 点击来源芯片或卡片核对原文，判断信息是否可信。

## 依赖前提
- Windows 操作系统（具体最低版本未说明）。
- 网络连接，用于检索公开网页和调用 AI 模型。
- 其他运行时依赖（如 API Key、浏览器内核）未在 README 披露。
