## 它是什么

AnyModelBot 是一个开源、本地优先的桌面应用（Windows / macOS / Linux），可创建多个 AI 机器人，每个机器人有自己的人设、默认模型、工作区和记忆。它不只是聊天窗口，还能读写文件、在沙箱中执行命令，经审批后操作桌面。模型可通过 Modelflare 聚合登录按量付费，也可用官方 API Key 直连 OpenAI、Anthropic、Google Gemini、xAI、DeepSeek、Kimi、GLM 等厂商。对话、记忆、文件和 API Key 留在设备上，MIT 许可，无订阅费。

## 为什么火

仓库 Star 数短时间达到 4289，定位上直接对标 Grok Bot、OpenAI dots 和 Claude Duet，吸引不想被单一厂商绑定、又需要多模型的用户。相比官方聊天机器人，它把 AI 变成可执行文件操作、命令和桌面自动化的 Agent，并内置后台任务、定时规则、预算和审批卡片，降低了从「问答玩具」到「能干活」的门槛。按量付费、本地优先和渠道打通微信/飞书也是明显差异化。

## 技术栈

README 显示源码运行需要 Node.js 22.13+ 和 Go 1.26.8+，内置网关可能由 Go 编译；桌面端大概率基于 Electron（主题含 electron）。仓库语言标为 Python，可能用于部分技能、脚本或运行时工具，但 README 未说明三者具体分工。Docker 镜像同时支持 x64 和 arm64，适合 NAS/服务器部署。详细前端框架、本地存储结构、沙箱实现未在 README 展开。

## 核心能力

- 多机器人团队：每个人设、模型、工作区、记忆、头像均可配置，三档权限：只读 / 工作区 / 完全权限。
- 文件与命令执行：沙箱内运行，写入工作区以外需审批卡片确认。
- 后台任务与规则：定时检查、主动消息、免打扰时段、每日主动消息上限、任务预算与自动清理。
- 记忆：全局「关于我」在所有机器人间共享，每个机器人也有独立记忆。
- 渠道接入：应用内、微信、飞书、Telegram、Slack、Discord。
- 电脑操作：由 Cua Driver 提供，可设置每步审批；macOS 上为 Beta。
- 图片/视频生成：通过 Modelflare 按量计费，高成本前先确认。
- 群聊与机器人间协作：@ 指定、任务交接、以他人名义审批。
- 现成 Bot：尽调助手、PPT 大师、影视创作室、美股研报。
- 搜索、斜杠命令、模型选择器、多 API 域名、本地聊天记录检索。

## 适用场景

适合想自托管、多模型并行、不希望被单一订阅绑定的个人或小团队；需要 AI 处理本地文件、定时调研、生成报告，并希望通过微信/飞书接收结果的人。桌面自动化也在受控审批下可用。影视创作室 Bot 需要本机 Python 3.10+ 和 FFmpeg，电脑操作在 macOS 上是 Beta，部署到公网需自行注意端口安全。

## 同类对比

与 Grok Bot、OpenAI dots、Claude Duet 相比，AnyModelBot 的主打差异是本地优先、多模型选择、按量付费，以及把聊天机器人扩展到文件/命令/桌面操作和后台任务。相比纯 API 聚合客户端，它更接近 Agent 团队管理；相比自建 Agent 框架，它有开箱即用的桌面应用、审批卡片和渠道接入。不过 README 没有给出逐项功能对比数据，实际优势需要按个人工作流验证。
