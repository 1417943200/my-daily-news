## 它是什么
AnyModelBot 是一个开源（MIT）桌面应用，可在 Windows/macOS/Linux 运行，也支持 Docker 部署。它把多个 AI 机器人组成“团队”，每个机器人有独立人设、默认模型、工作区和记忆。模型来源二选一：通过 Modelflare 账号使用 70+ 模型（GPT、Claude、Gemini、Grok、DeepSeek、Kimi、GLM 等），或使用官方 API Key 直连 OpenAI/Anthropic/Google/xAI/DeepSeek 等。应用内可聊天，也可接入微信、飞书、Telegram、Slack、Discord。关键定位：本地优先，对话/记忆/文件/API Key 留在本机，应用本身不收费，模型按量付费。

## 为什么火
项目创建时间短（2026-10-27），但已获 4.6k Star。核心吸引力是它试图把“AI agent 操作系统”变成开箱即用的本地工具：不是只能聊天，而是能读写文件、执行命令、操作桌面、跑后台任务和定时规则；所有危险操作通过审批卡片确认。对不想把个人数据和文件交给云端 bot 的用户，以及需要多渠道触达（尤其是微信/飞书）的国内用户，这点很直接。相比官方 Grok Bot / OpenAI dots / Claude Duet，它用多模型聚合和本地优先做差异化。

## 技术栈
README 没有给出完整架构图，以下主要来自构建说明和主题标签：
- 桌面端：Windows/macOS/Linux 安装包；源码运行需要 Node.js 22.13+，管理界面通过 http://127.0.0.1:3600/ 访问。
- 内置网关：源码构建需要 Go 1.26.8+；Docker 镜像暴露 3600 端口并提供 `ui-token` 鉴权。

- 电脑操作由内置 Cua Driver 提供；运行时基于 DeepSeek Harness，设计参考 DeepSeek Super Agent 原型。

## 核心能力
- 多机器人团队：每个机器人有独立人设、默认模型、工作区、记忆；权限分只读/工作区/完全权限三档。
- 真实工具执行：读写文件、沙箱内执行命令、操作桌面（点击/输入可要求逐次审批）。
- 审批卡：写工作区之外、删除大范围、费用超阈值等都会暂停等待确认。
- 后台任务与规则：可后台执行调研/报告/整理；支持“每天早上 8 点查 X 价格”类定时规则，有预算、免打扰和每日主动消息上限。
- 技能系统：可导入/安装/自存技能，存成 `SKILL.md` ZIP，跨机器人复用、导出、设成定时。
- 多渠道接入：应用内聊天 + 微信/飞书/Telegram/Slack/Discord；支持群聊和机器人间协作。
- 任意模型：Modelflare 聚合或官方 API Key 直连；按对话切换模型，后台小任务可单独指定模型。
- 记忆：分“关于我”全局记忆和机器人私有记忆，可查看/修改/撤销。
- 现成 Bot：尽调助手、PPT 大师、影视创作室、美股研报，内置本地安装。

## 适用场景
- 桌面/文件自动化：整理文件夹、批量改文档、写报告，且不想把文件传上云。
- 多渠道个人助理：在微信或飞书里直接指挥 bot 处理任务，适合国内办公场景。
- 多模型重度用户：想在同一界面切换 GPT/Claude/Gemini/DeepSeek 等，并且只按用量付费。
- 自托管/NAS 部署：Docker 一键跑在自己的服务器上，作为私有 agent 网关。
- 内容生成：PPT、短视频/短剧、美股研报、公司尽调等现成 Bot 降低入门门槛。

## 同类对比
README 明确将自身定位为 Grok Bot、OpenAI dots、Claude Duet 的开源本地优先替代。与这些官方 bot 相比，它的差异点在于：本地保存数据、不锁定单一模型、可自托管、能接入微信/飞书等渠道、允许通过官方 Key 直连厂商。但需要注意：项目非常年轻（v0.1.42），生态和稳定性未经长期验证；官方 bots 可能在特定模型或图像生成上更深度集成。与其他开源 agent 框架相比，README 未提供可量化对比，无法评价任务成功率或性能。
