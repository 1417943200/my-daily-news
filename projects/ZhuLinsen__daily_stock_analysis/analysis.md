## 它是什么
LLM 驱动的多市场股票智能分析系统，覆盖 A股/港股/美股/日股/韩股/台股和 ETF。每日自动运行，生成包含评分、趋势、买卖点、风险警报、催化因素等内容的决策仪表盘，并推送至企业微信、飞书、Telegram、Discord、Slack 或邮箱。支持 GitHub Actions 零成本定时运行，也可以本地或 Docker 部署。

## 为什么火
Star 数高（72,786），2026 年 1 月创建后快速迭代。核心吸引力在于把散户日常“看行情、读新闻、写结论”的流程自动化，用 LLM 把多源数据加工成可执行的决策建议，且默认内置免费数据源，零配置即可跑通；对多市场和多推送渠道的支持减少了自建脚本的维护成本。

## 技术栈
Python 3.10+。LLM 侧支持 Modelflare、x6.ai、AIHubMix、Gemini、OpenAI 兼容、DeepSeek、通义千问、Claude、Ollama 本地模型等。行情数据源包括 TickPlus（推荐）、AkShare、Tushare、Pytdx、Baostock、YFinance、Longbridge。新闻搜索支持 SerpAPI、Anspire、Tavily、Bocha、Brave、MiniMax、SearXNG；美股可选社交舆情源（Reddit/X/Polymarket）。部署方式：GitHub Actions、Docker、本地定时、FastAPI 服务。

## 核心能力
- AI 决策报告：核心结论、评分、趋势、买卖点位、风险警报、催化因素、操作检查清单。
- 多市场数据聚合：行情、K线、技术指标、新闻、公告、基本面与报告辅助数据。
- Web/桌面工作台：手动分析、任务进度、历史报告、回测、持仓、配置管理，支持浅色/深色主题。
- Agent 策略问股：多轮追问，内置 15 种策略（均线、缠论、波浪、趋势、热点、事件、成长、预期等），支持 Web/Bot/API。
- 智能导入：图片、CSV/Excel、剪贴板导入，代码/名称/拼音/别名补全。
- 自动化与推送：企业微信/飞书/Telegram/Discord/Slack/邮件。

## 适用场景
- 个人投资者每日复盘自选股，减少手动搜集信息时间。
- 想用 GitHub Actions 零成本跑定时分析，又不想维护服务器的极客。
- 需要多市场（A/港/美/日/韩/台）日报或盘中推送的轻度量化玩家。
- 希望用自然语言追问策略（如缠论、波浪）而不是只看到数值的 LLM 应用开发者。
