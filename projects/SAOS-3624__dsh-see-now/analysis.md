## 它是什么

一个给 DSH 用的实时视觉插件：把屏幕/摄像头/视频流按“变化分”筛选，留下来的帧拼成一张宫格图再交给模型。静止画面几乎不产图，动态内容按运动量出帧。默认画布 798×462，一张约 222 token（按宿主 DeepSeek-V4 patch 口径）。

## 为什么火

直观方案“定时截屏”有两个死结：每 2 秒一张 token 烧穿，间隔长又漏帧。它换个思路：先判断帧值不值得看，再决定传不传。硬切每换一次留一帧，连续运动靠积分攒采样点，静止只给 20 秒兜底帧。多帧拼进同一张图，固定成本摊到 4~8 帧，“多留一帧几乎免费”。这种 token 高效路线对常驻 AI 视觉上下文很有吸引力。

## 技术栈

- 主包：JavaScript，不依赖 DSH，capture / pipeline / png 独立导出
- 屏幕采集：Windows ddagrab/gdigrab；macOS avfoundation；Linux xdg-desktop-portal ScreenCast → PipeWire → GStreamer
- 悬浮窗：上游 Python/Tk（window.py 由 sync-window.mjs 生成），macOS/Linux 默认静态磨砂
- 可选：ffmpeg（file/rtmp 源）、ASR 转写（宿主导入 speechToText 或 OpenAI 兼容服务）、TTS 适配器动态加载

## 核心能力

- 变化分：HSV 三通道加权差，64×36 网格，约 0.2ms
- 出帧策略：画面突然换算 cut，持续运动积分出帧，静止 20 秒兜底
- 宫格拼图：一份 token 成本装 4~8 帧，带时间码、档位、来源清单
- 台词转写：视频里的语音以时间码映射到对应帧，模型能对上画面
- 悬浮窗 + 斜杠命令：/seenow 开关、状态、显示隐藏；say 通道可 TTS
- 子代理成本对照：子代理看一轮约 22,000 token（约 99 张宫格），长任务才划算

## 适用场景

- AI 陪看屏幕：远程指导、操作陪看、直播购物/课程内容跟踪
- 视频理解：一镜到底画面按运动量给帧，硬切幻灯片每切一帧
- 长会话/长任务：默认节奏 15~40 秒一张；真正长任务派子代理看几百次后总结
- 作为普通 Node 库：自己写自定义采集/管线

## 同类对比

README 没有与具体同类项目做横向对比，主要对比的是“定时截屏”原始方案：每 2 秒全屏重复烧 token，或长间隔丢失过程；该插件把成本从数十张/分钟降到默认节奏下 1~2 张/30 秒数量级。子代理方案也比主模型自己看图贵约 99 倍（就单次“看一眼”而言）。
