## 它是什么

Pinky 是一个开源（Apache-2.0）跨平台工具，让任意 MCP agent（Claude Code、Claude Desktop、Codex、Cursor 等）操作真实 iPhone 或 Android 手机，关键操作需人在环路审批。也可以用 Pinky 手机端 App 独立执行任务，无需电脑。项目处于 pre-alpha，作者 DIYgod。

## 为什么火

- 手机自动化风险高，普通 agent 直接操作容易失控。Pinky 在网关层强制执行审批，不靠提示词约束，覆盖支付、发送、删除、安装等高风险按钮，且支持 10 种语言识别。
- 跨双平台：Android 10–17 与 iOS 17.4+，有隐藏第二屏、后台任务、远程解锁等能力。
- 全本地、小体积（16–22 MB 下载，约 70 MB 内存，0% CPU），无 Electron/webview；多个模型可选，包括本地 Ollama/LM Studio。
- 项目创建于 2026-11-06，10 天左右已有 2287 Star，更新频繁。

## 技术栈

- 主语言 Go；UI 使用 MyGo（egoist/mygo）在 GPU 上绘制，无 Electron/webview。
- 通过 MCP 暴露手机控制能力，支持 stdio 与 HTTP 方式连接 agent。
- Android：自带 adb，通过 USB 或无线调试；Android 13+ 支持隐藏第二屏，需安装 Pinky 手机端 App。
- iOS：需要 Xcode 的 developer disk image（或第三方镜像），iOS 17.4–26 还要安装 Pinky 的 iPhone App；iOS 27+ 无需额外安装（已验证部分）。
- 支持多种模型：DeepSeek、Qwen、Kimi、GLM、Claude、GPT、Gemini，以及本地 Ollama/LM Studio。

## 核心能力

- **安全审批网关**：支付、转账、发送、删除、通话、安装、外链/设置更改等风险步骤默认等待用户点击 Allow；银行、钱包、密码管理器默认对 agent 不可见；密码/OTC 输入框禁止写入。
- **人在环交互**：可随时接管（点击镜像、手机触摸即可暂停 agent），全局快捷键停止。
- **记录与回放**：每个步骤有文字、截图、屏幕录像，标有步骤标记，可导出 HTML 报告，全部留本地。
- **第二屏幕/离屏操作**：Android 13+ 的 agent 在隐藏屏幕上工作，不影响用户使用手机。
- **手机独立运行**：Pinky App 可在手机上直接执行任务，支持语音/文本/分享触发，Android 有悬浮按钮询问屏幕内容，并可后台隐藏屏幕执行。
- **定时任务与记忆**：可按设定时间运行，或条件满足时通知；任务后可建议记住偏好，需用户确认。
- **远程解锁**：保存 PIN 后通过 Touch ID/Windows Hello/钥匙串确认解锁，agent 不会看到 PIN。
- **录屏文件夹管理**（最新版本）：可选择外部磁盘，处理磁盘缺失/只读，删除任务时同步清理。

## 适用场景

- 想用 Claude Code 等 agent 操控手机完成真实任务的开发者/极客：发消息、点餐、支付前审批。
- 需要在 Android 和 iOS 上自动化跨 App 流程，同时保持人工监管。
- 想训练/评测手机 agent 的研究者（有 ACCEPTANCE.md 等文档，本地记录）。
- 想用手机端独立执行自动化任务，不想开电脑的用户。

## 同类对比

README 没有直接点名同类，但明显区别于仅提供手机屏幕截图/坐标点击的 MCP 工具：Pinky 强在审批网关（默认高风险操作等待人工）、跨平台 Android+iOS、Android 隐藏第二屏、记录可审计、手机端可独立跑。对“AI 操作手机”这个方向，它是偏安全与可审计的选择，而不是最简原型。

## 版本动态

最新版本 v2026.1117.1（2026-11-16）主要改进录屏存储：
- 可在 Settings › Privacy › 录屏文件夹 选择保存位置，如外接硬盘；新录屏去新位置，旧录屏仍可播放，可一键切回默认文件夹。
- 磁盘不可用或只读时自动回退到 Pinky 自己的文件夹，并在设置有提示，禁止选在其自身录屏文件夹内。
- 删除任务时同步删除所选文件夹中的录屏，即使磁盘当时未挂载/只读，也能在后续可访问时清理；删除所有活动只删 Pinky 的录屏，不碰用户其他文件。
