- 准备一台 Android 8.0+、ARM64 架构的手机，预留至少 2GB 以上存储（APK 729 MiB + 运行数据）。
- 从 GitHub Releases 下载 v1.5.0 的 APK，安装后打开 App，按引导完成环境初始化（无需 Root）。
- 启动 AstrBot，等待“管理后台就绪”状态。
- 在首页选择“QQ 官方机器人”或“微信官方机器人”，扫码授权后自动保存接入。
- 进入“网页”或首页的 WebUI 入口，配置模型 API Key 和插件/人设。
- 按需在“设置 → 后台运行”中调整电池优化、自启动等权限，保证长期运行。
- 依赖前提：外网/内网可访问（模型与更新需要网络），不需要 Root。无其他硬性依赖。
