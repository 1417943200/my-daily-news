## 它是什么
Mika 是一个运行在 Android 上的本地优先 AI 代理，通过屏幕理解直接操作手机应用和网页。它在隐藏后台屏幕上执行任务，不打断用户正常使用。没有 Mika 服务器，用户需自带模型 API key 或登录 ChatGPT/xAI/OpenRouter，数据只发给自己配置的模型提供商。

## 为什么火
- 8.8k star，Apache-2.0 开源，创建于 2026-10-29，快速增长。
- 解决手机上自动化痛点：传统自动化需要 root 或每应用适配，Mika 像人一样看屏操作，号称任意应用可用。
- 隐私优先：密钥和记忆加密存储在手机，对话和运行记录留在设备，更新检查只连 GitHub。

## 技术栈
- Kotlin + Jetpack Compose（仓库语言和主题推断 UI 层）
- 依赖 Android 无障碍/屏幕捕获（主题含 accessibility），无 app API、无每应用集成
- 内置桌面级浏览器，保持登录态，可读页面、下载上传
- Linux sandbox（arm64）运行 Python、Node、shell
- 支持 OpenAI-compatible、Anthropic、Gemini 等模型端点，可自定义本地端点
- 后台屏幕技术，Android 14+ 有独立焦点，不干扰主屏输入

## 核心能力
- 操作任意 App/网页：阅读长列表、点击、输入、分享；登录、验证码、支付转交用户
- 内置浏览器读页、下载上传，自动处理验证页转交用户
- 浮动胶囊双击发送当前屏幕，长按语音，按住说话
- 定时/条件触发；任务运行中可随时插话、停止、继续
- Ask/Autonomous 两种模式，花钱前默认确认
- 记忆用户偏好，将完成的任务沉淀为技能
- 内置应用/网站使用知识，覆盖微信、淘宝、Amazon、Google Calendar 等常见应用和网站
- 多语言 UI，支持英语、简中、繁中、日语、韩语等

## 适用场景
- 手机端日常自动化：发微信、总结群聊、购物加购、订机票、刷新闻等
- 不想 root 但想用 AI 操作手机的重度用户/极客
- 需要隐私可控的本地 Agent 实验
- 从电脑通过 CLI/Skill/MCP 调用手机 Agent 的混合工作流

## 同类对比
README 未列出直接竞品。从其定位看，区别于需要 root 的自动化方案和依赖官方 API 的集成方案；Mika 强调视觉+无障碍、任意 App 可用、后台运行不打断前台使用。与桌面端 GUI Agent 思路类似，但聚焦 Android、强调本地优先和隐藏后台屏幕。
