## 它是什么
Mika 是 Android 设备端 AI 代理，用自然语言下指令，它在隐藏后台屏幕上操作手机应用和网页直到任务完成，不打断用户正常使用手机。项目开源（Apache-2.0），无自有服务器，用户配置自己的模型 API key 或登录 ChatGPT/xAI/OpenRouter 账号，数据只发送到所选的模型提供商。

## 为什么火
项目创建不到一个月 Star 达 9086，曾登 Kotlin 日/周趋势榜第一。核心吸引力在于：通用 UI 自动化不需要每个 App 提供 API，像人一样看屏找按钮；后台屏幕隔离，任务运行时不影响前台操作；隐私架构清晰，无 Mika 服务器，密钥和记忆加密存储；开源免费且有大量中文应用内置知识。

## 技术栈
- 语言：Kotlin
- UI：Jetpack Compose（项目主题标签）
- 应用操控：依赖 Android 无线调试/后台屏幕机制，Android 14+ 有独立焦点，推荐用于流畅体验
- 模型接入：支持 DeepSeek、通义千问、Kimi、OpenAI、Anthropic、Gemini、Ollama 等，兼容 OpenAI-compatible、Anthropic、Gemini、OpenAI Responses 端点
- 计算沙箱：arm64 设备上每会话有 Linux sandbox，可运行 Python、Node、shell
- 电脑协作：提供 CLI + Skill 和 MCP 接口
- 隐私存储：API key 和记忆加密存储，会话与运行记录留在设备

## 核心能力
- 后台操控任意 App：打开、点击、输入、滑动、长列表阅读、聊天记录读取，支持登录、验证码、支付时交给用户
- 内置桌面级浏览器：保持登录、读页面、上传下载，可对当前页面直接下指令
- 当前屏幕协作：双击悬浮胶囊发送当前屏幕，询问回复或记录
- 定时和条件任务：如“明天 9 点提醒我”或“每早 8 点查天气，下雨才告诉我”
- 实时干预：任务执行中可继续对话追加/纠正，长按撤回未执行指令，停止后可续跑
- 语音输入：按住输入栏或长按悬浮胶囊说话
- 文件处理：发送文件给会话内 Linux 沙箱进行 Python/Node/shell 处理
- 内置应用/网站知识：微信、淘宝、小红书、Amazon、YouTube 等数十个主流应用和网站
- 模式：默认 Ask 模式只在花钱前确认；可切 Autonomous 模式

## 适用场景
- 日常手机自动化：发微信、总结群聊、比价加购、点外卖、抢优惠券等
- 网页任务：查航班、总结帖子、下载上传文件
- 定时监控与提醒：天气预警、周期任务
- 隐私敏感的端侧 Agent 需求，不愿将手机屏幕数据交给第三方服务器
- 开发者通过 CLI/MCP 从电脑驱动手机完成多步任务

## 同类对比
README 未直接点名同类，但可对比方向：
- 对比规则型自动化（Tasker/Automate）：Mika 用视觉模型理解屏幕，无需为每个 App 写脚本，泛化能力更强
- 对比测试框架（Appium）：测试框架偏结构化定位，Mika 面向自然语言端到端任务执行
- 对比网页 Agent：Mika 深度集成 Android 后台屏幕，能操控本地 App 而非仅浏览器
不足：无 benchmark 数据，任务成功率、耗时、资源占用未量化；部分敏感页面仍需人工接管。
