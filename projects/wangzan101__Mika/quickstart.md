## 安装
1. 从 GitHub Releases 下载最新 APK（要求 Android 11+）
2. 打开设置 → Model，选择提供商并填入 API key，或登录 ChatGPT/xAI/OpenRouter 账号
3. 如需操控手机应用：进入设置运行“Set up phone control”向导，配对无线调试（一次性）；Android 14+ 推荐
4. 只想用聊天、网页、文件功能可跳过第 3 步

## 最小可用示例
- 说：“Set alarms for 9:40 and 10:00 tomorrow morning”
- 说：“Check the weather at 8 every morning and tell me only if it will rain”
- 浏览器中打开某网页，告诉 Mika 你要对该页做什么

## 依赖前提
- Android 11+：聊天、网页、文件
- Android 12+：操控手机应用，Android 14+ 推荐（后台屏幕有独立焦点）
- arm64 设备：使用 Linux sandbox
- 自备模型 API key 或受支持的第三方账号
- 无线调试需系统支持；部分手机缺失该功能时可用 USB 连接电脑启动 helper
- 操控第三方应用可能违反其服务条款，重要操作建议使用 Ask 模式
