## 安装
从 Releases 下载 APK，要求 Android 11+（聊天/网页/文件），操作 App 需 Android 12+（推荐 Android 14+），Linux sandbox 需 arm64。

## 连接模型
设置 › 模型，选择提供商输入 API key，或登录 ChatGPT/xAI/OpenRouter；也可自定义 OpenAI-compatible 端点。

## 操作手机 App
在设置中运行“Set up phone control”向导，配对无线调试（需开发者选项，部分系统可能需 USB 辅助）。

## 最小示例
安装后连接模型，直接对话：“明天早上 9:40 和 10:00 设两个闹钟”或“每天早上 8 点查天气，只在有雨时告诉我”。如需操作 App，先完成 phone control 配对，然后说“给文件传输助手发条消息”。

## 依赖前提
Android 11+，arm64（若用 Linux sandbox），模型 API key 或支持的账号，无线调试配对（若操作 App）。
