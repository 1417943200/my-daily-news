## 安装

1. 从 GitHub Releases 下载 `whale-girl-4.1.7-setup.exe`（仅从官方发布源下载）。
2. 运行安装器，安装到 ASCII-only 路径如 `D:\whale-girl`。
3. 启动桌面快捷方式「Whale Girl」。

## 最小可用示例

1. 打开启动器 Settings，选模型 provider（如 DeepSeek）并填 API key。
2. 进入 WeChat bridge，选择已登录的微信 4.x 账号，点 Start。
3. 等 Status 页显示 kernel 和 bridge 都 running。
4. 在微信群里 @机器人或叫名字，它会回复；私聊会记住事实。

## 依赖前提

- Windows 10/11
- 已登录的微信 4.x 账号（建议小号）
- DeepSeek/Qwen/GLM/SiliconFlow/豆包/OpenAI 兼容 API key 之一
- 可选：Ollama 或其他本地 OpenAI 兼容服务
- 微信 UIA 自动化需要管理员权限
- 安装路径不能含中文（ASCII-only）
