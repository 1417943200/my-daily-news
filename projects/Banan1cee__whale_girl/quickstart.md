## 安装

1. 从 GitHub Releases 下载 `whale-girl-*-setup.exe`
2. 运行安装，确保路径为 ASCII（如 `D:\whale-girl`）
3. 打开桌面快捷方式启动 WhaleLauncher.exe

## 最小可用

1. 在启动器 Settings 选择模型提供商（如 DeepSeek），填入 API key
2. 打开 WeChat bridge，选择已登录的微信账号，点击 Start
3. 等待 Status 页显示 kernel 和 bridge 均 running
4. 在微信群中 @机器人 或叫它的名字，即可触发回复

## 依赖前提

- Windows 10/11
- 已登录微信 4.x 账号（建议小号）
- 一个模型 API key（DeepSeek/Qwen/SiliconFlow 等）
- 管理员权限（用于 UIA 自动化）
- 可选：本地模型服务（Ollama）
