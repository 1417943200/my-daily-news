## 它是什么

Whale Girl 是一个本地优先的微信 AI 伴侣，让 DeepSeek/Qwen 等模型用你的微信账号在群聊和私聊中陪聊。Windows 桌面端由 WPF 启动器管理，Node.js 内核处理消息，Python 桥接通过 UIA 自动化控制微信 4.x。无浏览器 UI，本地 HTTP API 仅绑定 127.0.0.1。

## 为什么火

Star 746，解决个人微信接入 LLM 的痛点：无需 Hook 或协议破解，用 UI 自动化读取本地微信窗口和数据库。打包了 Node.js、Python 3.12 和 .NET 10 运行时，安装即用，对 Windows 用户友好。AGPL-3.0 开源，有活跃的插件市场和社区贡献。

## 技术栈

- 内核：Node.js（CommonJS，零 npm 运行时依赖）
- 桥接：Python 3.12 + wechatauto（基于 UI Automation）
- 启动器：WPF (.NET 10)
- 打包：Inno Setup，内置 Node.js、Python 3.12、.NET 10 运行时
- 模型：DeepSeek、Zhipu、SiliconFlow、Qwen、Doubao、OpenCode 或任何 OpenAI 兼容端点；可选 Ollama

## 核心能力

- 群聊回复：@提及和名字触发，保持话题活跃，适时安静
- 记忆：记录事实、压缩群历史，图片/表情包不可读时保持沉默
- 人类化交付：短气泡拆分、避免尾部标点、避免重复回复
- 扩展：表情包（27 内置+自定义）、朋友圈读取、Markdown 日记、语音（ASR/TTS）、搜索、群管理
- 诊断：内置日志、账号检查、UIA 自检、更新检查

## 适用场景

想在个人微信上部署一个可控的 AI 陪聊/助手，愿意承担微信账号风险，且熟悉 Windows 桌面环境。适合个人自托管、群聊互动实验，不适合生产级客服或需要高稳定性的场景。

## 同类对比

与 wechaty 等协议级机器人相比，本方案走 UI 自动化路线，不注入代码但依赖窗口状态和 UI 结构，可能更脆弱；与 wxauto/wechatauto 等自动化库相比，它提供了完整的产品化外壳（启动器、插件市场、多模型适配），开箱即用程度更高。
