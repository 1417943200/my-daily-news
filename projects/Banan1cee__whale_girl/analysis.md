## 它是什么

鲸鲸（Whale Girl）是一个 Windows 本地优先的微信 AI 陪聊机器人：用你的真实微信账号，在群聊/私聊中扮演一个可配置人设的「AI 群友」。它由 Node.js 内核 + Python UIA 桥接 + WPF 启动器组成，无浏览器 UI，仅通过 `127.0.0.1:8787` 暴露本地 HTTP API。默认支持 DeepSeek/Qwen 等模型接口。

## 为什么火

679 star、创建仅约三周左右（2026-10-26 至最近推送 2026-11-16）说明关注点在于：它把「微信 4.x UIA 自动化」和「本地优先 AI 角色扮演」打包成一个开箱即用安装器；不注入微信、不 patch，记录存本地，且提供完整的群聊记忆、日记、语音、朋友圈等功能。对想低成本在微信里养 AI 群友又不想用云托管/Web 协议的用户有吸引力。

## 技术栈

- 内核：Node.js（CommonJS，零 npm 运行时依赖）
- 桥接：Python 3.12 + `wechatauto-replica`（Windows 微信 4.x UIA 自动化，vendor 固定版本）
- 桌面启动器：WPF（.NET 10 runtime）
- 安装器：Inno Setup，由 GitHub Actions 构建
- 模型：DeepSeek、千问、智谱 GLM、SiliconFlow、豆包、OpenCode 或任意 OpenAI 兼容端点；可接 Ollama 本地
- 本地 API：`127.0.0.1:8787`，无登录层

## 核心能力

- 群聊 @/名字触发回复，私聊持续对话并提取记忆
- 压缩旧群聊历史、主人/管理员规则
- 人性化拆气泡、去尾标、避免复读
- 表情包、朋友圈阅读/互动、Markdown 日记、语音收发、联网搜索、热榜、基础群管理
- 插件市场（社区插件，README 明确不保证安全）
- 内置诊断、UIA 自检、更新检查

## 适用场景

- 有 Windows 10/11 和微信 4.x 小号，想跑一个常驻 AI 群友或私聊助理
- 愿意自己配 DeepSeek/Qwen 等 API Key、接受 UI 自动化可能违反微信服务条款的风险
- 对本地数据、可换人设、自动化生成日记/互动感兴趣的极客

## 同类对比

它和常见的微信机器人路线不同：不做 Web 协议或 hook 注入，而是基于 `wechatauto-replica`（受 `wxauto` 启发）的 UIA 自动化，因此对微信客户端版本敏感、需要管理员权限和本地窗口交互，但安装友好、无浏览器 UI、数据本地。相比纯聊天框架，它更偏「角色扮演陪伴 + 生活功能（日记/朋友圈/语音）」，而非通用消息推送。

## 版本动态

v4.1.7（2026-11-16）主要修了强制更新策略（精确 `force_versions` 名单）、语音/搜索 API 默认跟随聊天模型、运行包遗漏 SILK 解码依赖、链接阅读阻塞、UIA 巡检保护。安装器仍未代码签名，需核对 `SHA256SUMS.txt`；已包含配置保护与人设保存修复，4.1.7 具备迁移能力。
